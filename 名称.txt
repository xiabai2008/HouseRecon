### 定名：屋勘（HouseRecon）
这个名字平衡得非常好：「屋」精准对应 House，保留了你偏好的“宅”内核但克制不生硬；「勘」直指勘察、测绘、信息搜集，是网安测绘类工具的标准用字，整体干净利落，外表是正经专业工具名，内核藏着个人喜好的小梗，和「转子女神」的命名逻辑完全对齐。

---

**一屋之内，勘遍全网**

### README 开篇文案（可直接复用）
#### 一句话项目定位
屋勘（HouseRecon）是一款轻量化网络空间资产侦察与信息收集工具，以低交互模式完成目标资产测绘、指纹识别与痕迹搜集。

#### 完整介绍
屋勘，取义「屋中勘察」，对应英文名 HouseRecon。工具主打轻量、静默的信息收集模式，支持子域名枚举、端口扫描、服务指纹识别、站点信息爬取等常用侦察场景，帮助安全从业者在尽可能少暴露自身特征的前提下，快速完成目标资产清点与情报梳理。

---

### 落地实用细节
1. **命令行调用名**
推荐使用 `wukan` 作为二进制文件名，拼音简短易记，符合命令行工具输入习惯：
```bash
wukan -u example.com -o result.csv
```

2. **Logo创意方向**
- 极简专业风：简约房屋轮廓内嵌一道横向扫描线，线条干净，暗合“屋内向外观测”的核心意象，适合正式项目仓库。
- 像素趣味风：像素小房子窗口伸出一枚望远镜，辨识度高，适合开源社区传播。

3. **启动页小彩蛋**
工具启动时可打印简易ASCII房屋图案搭配短标语，个人工具的专属感拉满，示例：
```
  /\
 /  \
/____\
|  [] |  屋勘 HouseRecon
|_____|  一屋之内，勘遍全网
```
